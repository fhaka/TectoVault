# TectoVault brand

- **[brand-guide.pdf](brand-guide.pdf)** — the brand guide (logo, colours, typography, voice, ready-to-use copy).
  The source is [brand-guide.html](brand-guide.html); open it in a browser from this folder, or
  re-export the PDF with your browser's *Print → Save as PDF* (enable background graphics).
- **[logo/](logo/)** — logo files:
  - `tectovault-logo.svg` — full colour, for white or very light backgrounds
  - `tectovault-logo-white.svg` — for dark backgrounds and photos
  - `tectovault-logo-dark.svg` — one colour (documents, invoices, stamps)
  - `tectovault-mark.svg` — icon only (avatars, favicons)

**Tagline:** *AI agents that work for your business.* / *Agjentë AI që punojnë për biznesin tuaj.*

The SVGs were traced from the website's 696 × 147 px logo: sharp at any screen size. For large-format
print, ask the original designer for the master vector file.

Legal templates (draft, for lawyer review) are in [../legal](../legal).
